# موقع Mohamed Mohy — دليل التعديل والنشر

## تشغيل الموقع
1. فك ضغط الملف.
2. افتح المجلد `mohamed_mohy_portfolio`.
3. افتح `index.html` في المتصفح لمعاينة الموقع مباشرة. لا يحتاج إلى تثبيت أو خادم برمجي.
4. لتعديل الكود، استخدم أي محرر نصوص، والأفضل VS Code.

## تعديل الأرقام
افتح `data.js` وعدّل القيم الرقمية فقط، بدون فواصل أو نصوص داخل الرقم. مثال:
```js
adSpendEGP: 35000
```
يمكن تغييرها إلى:
```js
adSpendEGP: 40000
```
ثم احفظ الملف وأعد تحميل الصفحة. البيانات لا تُعدّل من واجهة الزائر، بل من الملف يدويًا.

الأرقام الموجودة حاليًا:
- الرعاية الصحية: 35,000 جنيه إنفاق، وأعداد شهرية مُبلّغ عنها 900 و1,100 و1,200.
- حملة الإنشاءات والتشطيبات: 30,000 جنيه إنفاق و1,300,000 جنيه إيرادات مُبلّغ عنها للشركة خلال الفترة، وليست إيرادات مثبتة ناتجة بالكامل عن الإعلانات.
- جميع المعارض: 250,000 جنيه إنفاق مُبلّغ عنه و70,000,000 جنيه إيرادات إجمالية مُبلّغ عنها.
- شركة إضافية: نحو 15,000 جنيه إنفاق شهري، ومعرضان ومصنعان.
- ذُكر أيضًا إنفاق يقارب 100,000 جنيه عبر شركات أخرى في القطاع، لكن لم يُعرض كرقم إجمالي مستقل لأن الفترة والنطاق قد يتداخلان مع أرقام أخرى. أكّد النطاق قبل نشر هذا الرقم.

## إضافة الصور
1. ضع صورك في `assets/projects/` أو في `assets/projects` بعد إنشائه.
2. خانات الصور الحالية عبارة عن placeholders وليست صورًا فعلية.
3. أسهل طريقة لتعيين صورة لخانة: في `index.html` ابحث عن `media-slot` للخانة المطلوبة، وأضف `style="background-image:url('assets/projects/your-image.jpg');"` ثم أضف class مثل `has-image`. مثال:
```html
<div class="media-slot has-image" style="background-image:url('assets/projects/healthcare-main.jpg')">
  <span class="slot-icon">＋</span>
  <span>Main campaign visual</span>
  <small>healthcare-main.jpg</small>
</div>
```
4. يمكنك تكرار عناصر `media-slot` لإضافة عدد أكبر من الصور. احتفظ بأسماء الملفات واضحة، وتجنب صور العملاء أو بياناتهم الحساسة دون إذن.

## معلومات التواصل
البريد ورقم واتساب موجودان في `index.html`. غيّر البريد في `mailto:` والنص الظاهر، ورقم واتساب في رابط `https://wa.me/` باستخدام رمز الدولة والأرقام فقط.

## اللغة
زر اللغة يبدّل بين الإنجليزية والعربية. النصوص موجودة في `script.js` داخل `translations.en` و`translations.ar`.

## النشر المجاني
يمكن نشر المجلد على GitHub Pages أو Netlify أو Cloudflare Pages. ارفع الملفات كما هي، مع إبقاء `index.html` في جذر الموقع. قبل النشر:
- استبدل خانات الصور بصور حقيقية.
- راجع جميع الأرقام وفترات المقارنة.
- تأكد من أن لديك حق عرض صور الحملات وأسماء العملاء.
- أضف رابط LinkedIn إن رغبت.
- جرّب الموقع على الهاتف وتأكد من عمل زر اللغة ووسائل التواصل.

## ملاحظة مهمة حول النتائج
إيرادات الشركة خلال فترة الحملات ليست بالضرورة إيرادات ناتجة بالكامل عن الإعلانات. لا تستخدمها لحساب ROAS إلا إذا كان لديك إسناد موثوق للإيرادات إلى الحملات.
